# 網易雲 → Discord 聽歌狀態

讓 Discord 顯示「正在聆聽 歌名 – 歌手」、專輯封面和進度條。手機（iPhone、Android）或電腦播網易雲都會顯示。不需要 Discord 密碼或 token。

只支援 Windows，而且要開著電腦版 Discord。

## 下載

到 [最新版本](https://github.com/LZ-cpu326/ncm-discord-rpc/releases/latest) 下載 `NcmDiscordRpc.zip`，解壓縮後照裡面的「使用說明.txt」操作。

安裝後程式會自動更新，不用再回來下載。

## 這個 repo

這裡只放發布檔，自動更新也是從這裡的 Releases 下載。登入資料只存在使用者自己的電腦（`%APPDATA%\NcmDiscordRpc`），不會上傳。
